- **Weather: location on by default (iPhone app fix)** · PR #TBD · Root cause: the iOS app's Info.plist had no `NSLocationWhenInUseUsageDescription`, so iOS silently refused location to the app's web view (browsers on the laptop don't need it). If you'd already denied it: Settings → Privacy & Security → Location Services → Live → While Using.
